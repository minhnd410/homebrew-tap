# minhnd410/homebrew-tap

Homebrew tap for [computer-control](https://github.com/minhnd410/computer-control) —
an MCP server that lets a model drive your desktop, and the phones on it.

```bash
brew install minhnd410/tap/computer-control
computer-control-mcp --request-permissions
```

`Formula/computer-control.rb` is generated by the upstream release workflow on
every tag, from the checksums CI computed. Do not edit it by hand; the next
release will overwrite it.
